# Frontend

Tauri + Nuxt application.

## Development

```bash
pnpm dev        # Run Tauri app with Nuxt dev server
pnpm nuxt:dev   # Run Nuxt only (web, no Tauri)
pnpm typecheck  # Type check
```

## Building

```bash
pnpm build       # Build Tauri app for current platform
pnpm nuxt:build  # Build Nuxt only
```

For more general information, check the [root readme](../../README.md).
